## 🏋️‍♂️ Overview
The **Gym Buddy App** is a simple yet powerful solution for anyone looking to track their fitness journey effectively. Designed for ease of use, the app enables users to create an account, log workouts, and monitor progress over time. Whether you're a fitness enthusiast or just starting your journey, the app provides a seamless way to record exercises, sets, and reps while ensuring your data remains secure and easily accessible.

With its emphasis on simplicity and functionality, the app offers a user-friendly interface optimized for desktop and mobile devices. The Gym Buddy App makes staying consistent with your fitness goals more manageable.

---

## ✨ Key Features

### **User Account Management**
- Create an account with a secure username and password.
- Log in to access your personalized workout data.

### **Exercise Logging**
- Add exercises by name (e.g., Bench Press, Squats).
- Record the number of sets and reps for each session.
- Edit or delete past entries as needed.

### **Progress Monitoring**
- View your exercise history to track improvements over time.
- Analyze trends in your workouts to set and achieve goals.

### **Responsive Design**
- Optimized for desktop and mobile devices, ensuring a smooth platform experience.

### **Data Security**
- User data is securely stored with encrypted passwords.
- Reliable database management to ensure data integrity.

## 💻 Technologies Used

The app is built using modern technologies to deliver a robust and scalable solution:

### **Frontend**
- **HTML**, **CSS**, **React.js** for a responsive and interactive user interface.

### **Backend**
- **Node.js** for efficient server-side operations.

### **Database**
- **MongoDB** to securely store user accounts and workout logs.

### **Authentication**
- Secure user authentication implemented with **JWT (JSON Web Tokens)**.

## 🚀 How to Use the App

### 1. **Sign Up**
- Create an account with your preferred username and password.

### 2. **Log In**
- Access your personalized dashboard to start logging exercises.

### 3. **Add Exercises**
- Enter the exercise name, number of sets, and reps for each workout session.
- Save the details to maintain a log of your workouts.

### 4. **Monitor Progress**
- Review your workout history on the dashboard.
- Use insights from your logs to track improvements and adjust your routine as needed.

## ▶️ Starting the App

Follow these steps to run the app locally:

 1. Clone the Repository
   ```bash
   git clone https://github.com/your-username/gym-buddy-app.git
   cd gym-buddy-app
```
 2. Install Dependencies
   ```bash
  # Frontend
cd frontend
npm install

# Backend
cd ../backend
npm install
```
3. Set up Database
- Make sure MongoDB is installed and running locally or use a cloud MongoDB service like MongoDB Atlas.
- Update the .env file in the backend directory with your database connection string.
```
4. Start the Application
Run the app's frontend and backend concurrently:
```bash
# Start the backend
cd backend
npm start

# Start the frontend
cd ../frontend
npm start
```
5. Access the App
Open your browser and navigate to http://localhost:3000 to start using the app.
